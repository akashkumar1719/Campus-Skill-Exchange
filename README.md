\# Campus Skill Exchange Platform



A web-based platform that enables college students to share skills, learn from peer mentors, and schedule learning sessions.



\## Overview



Campus Skill Exchange connects students who want to learn new skills with students who can teach them. It provides a collaborative environment for peer-to-peer learning and knowledge sharing.



\## Features



\- Student skill discovery

\- Mentor profiles and skill listings

\- Session booking and booking management

\- Mentor availability management

\- Session joining interface

\- Attendance management

\- Reviews and ratings

\- Study materials management

\## Getting Started



\### Prerequisites



\- Java and Maven wrapper support

\- Node.js and npm

\- MySQL Server



\### Run the Backend



Open a terminal:



```bash

cd backend

mvnw.cmd spring-boot:run

```



\### Run the Frontend



Open another terminal:



```bash

cd frontend

npm install

npm run dev

```



Open the local URL displayed by Vite in your terminal.



\## Database Configuration



Configure your MySQL connection using local application settings. Do not commit real passwords, API keys, or other secrets to GitHub.
